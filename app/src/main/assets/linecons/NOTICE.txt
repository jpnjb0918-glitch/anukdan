Drawing data for Anuki Launcher's generated cat icons ("고양이 아이콘", the 15,322 that are not hand-made)

Adapted from Arcticons by Donnnno and the Arcticons contributors
  Source: https://github.com/Arcticons-Team/Arcticons (icons/white, app/src/main/assets/appfilter.xml)
  Version used: commit 90a4343510f35e33421f0a41df5debc29c3604d1 (2026-10-05)
  Licence of the icons: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)
  https://creativecommons.org/licenses/by-sa/4.0/

Changes made:
  - SVG files converted to compact path data (names.txt, icons/*.txt) by tools/linecons/convert.py
  - closed outlines added as separate fill shapes (W elements) so they can be coloured in
  - appfilter.xml reduced to a package/class -> icon table (map/*.txt)
  - when shown in the launcher the lines are drawn thicker and black, closed shapes are filled white / pale cyan,
    and the drawing is placed on a tile inside the cat icon frame (assets/catfmt)
