# 아늑이 런처 (Anuki Launcher)

아늑단 캐릭터 아이콘으로 꾸민 안드로이드 홈 런처예요. 

## 설치

1. 이 저장소의 **Releases**에서 최신 `anuki-launcher.apk`를 휴대폰으로 받아요.
2. 설치할 때 "출처를 알 수 없는 앱" 허용을 물으면 허용해요.
3. 앱 목록의 **아늑이 런처 설정**을 열고 → **기본 홈 앱으로 설정**을 눌러요. (처음 홈 버튼을 눌렀을 때 아늑이 런처를 골라도 돼요.)

`main`에 올라갈 때마다 GitHub Actions가 APK를 새로 빌드해서 Releases에 올려요 (`.github/workflows/build.yml`).

### 업데이트

런처를 켜면 하루에 한 번 이 저장소의 최신 릴리스를 확인해서, 새 버전이 있으면 바뀐 점(지금 버전 이후 커밋 제목, 최대 6줄)과 함께 "업데이트하시겠습니까?"를 물어요. 설정 → 업데이트 확인으로 직접 확인할 때도 같아요. 각 릴리스 설명에도 "## 바뀐 점" 목록이 들어가요.

| 고른 것 | 동작 |
|---|---|
| 아니요 | 자동 알림을 꺼요 (설정 → "켤 때 새 버전 알림"으로 다시 켜기) |
| 예 → 기본판 | 휴대폰 다운로드 관리자로 받고, 끝나면 설치 화면이 자동으로 떠요 (처음 한 번 "이 출처 허용" 필요, 다른 앱을 쓰는 중이었다면 홈으로 돌아올 때) |
| 예 → 배지판 | 받은 뒤 설치 방법(Play 프로텍트 잠깐 끄기 / PC에서 USB 설치)을 안내해요 |

설정 → 업데이트 확인으로 언제든 직접 확인할 수 있어요. 이 기능 때문에 인터넷 권한과 앱 설치 권한(설치 화면 열기용, 설치는 직접 눌러야 함)이 들어 있어요.

### 설치 파일 두 가지

| 파일 | 차이 | 설치 |
|---|---|---|
| `anuki-launcher.apk` (기본판) | 알림 배지 없음 | 휴대폰에서 바로 설치 |
| `anuki-launcher-badge.apk` (배지판) | 알림 배지 있음 (알림 접근 서비스 포함) | 휴대폰 브라우저·메신저·파일 앱으로 설치하면 Google Play 프로텍트가 "기기 보호를 위해 앱 차단됨"으로 막을 수 있어요 |

Google은 브라우저·메신저·파일 관리자로 받은 앱이 알림 접근(`BIND_NOTIFICATION_LISTENER_SERVICE`), 접근성, SMS 읽기·받기 권한을 선언하면 일부 국가에서 설치를 자동으로 막아요([개발자 안내](https://developers.google.com/android/play-protect/warning-dev-guidance?hl=ko)). 배지는 알림 접근이 있어야만 셀 수 있어서, 이 기능만 배지판으로 나눴어요. 두 파일은 같은 앱(같은 서명)이라 하나만 설치하면 되고, 서로 덮어 설치할 수 있어요.

## 기능

| 구역 | 기능 |
|---|---|
| 홈 화면 | 여러 페이지, 격자 열·행 조절(3–10 × 3–12, 칸이 작으면 아이콘을 칸에 맞게 줄임), 독(3–7칸, 배경 켜기/끄기), 페이지 점 표시, 배치 잠금(옮기기·지우기·새로 놓기 막기), 새로 설치한 앱 자동 추가, 무한 스크롤, 상태 표시줄 숨기기 |
| 편집 | 길게 눌러 끌어 옮기기, 아이콘 위에 놓으면 폴더 만들기, 화면 가장자리에 대면 페이지 넘김, 위쪽 바에 놓아 제거·앱 정보·설치 삭제 |
| 길게 누르기 메뉴 | 앱 바로가기(기본 홈 앱일 때), 앱 정보, 아이콘 바꾸기, 홈에서 제거, 설치 삭제 / 빈 곳: 위젯 추가·배경화면·빈 페이지 삭제·설정 |
| 앱 서랍 | 위로 쓸어 열기, 아래로 쓸어 닫기, 검색(초성 검색 지원: `ㅋㅋㅇ` → 카카오톡, 계산식 답 `12*3` → 36, 단위 변환 `10km` → 6.214 mi · `25평` → 82.64㎡ · `30°C` → 86°F, 웹 검색, 연락처는 켤 때만), 사용자 탭, 앱 숨기기(지문·PIN 잠금 가능) / 형식 고르기: 세로 격자·가로 페이지·목록·가나다 묶음(오른쪽 막대로 이동)·종류별 묶음(게임·소셜·음악·사진 등 자동 분류) / 정렬: 이름순·최근 설치순·많이 연 순 / 배경: 테마 색·반투명·배경화면 보이게 |
| 폴더 | 이름 바꾸기, 색 4가지(청록·핑크·골드·네이비), 안의 앱 3개 미리보기, 커버 폴더(탭하면 첫 앱, 위로 쓸면 폴더 — 첫 앱 아이콘에 작은 폴더 표시) |
| 위젯 | 위젯 목록에서 추가(권한·설정 화면 처리), 옮기기, 삭제 / 크기 조절: 길게 눌러 '크기 조절' → 네 변의 손잡이를 끌어 한 칸씩(다른 아이콘이 있는 칸은 막힘), 크기 표시를 누르면 숫자로 조절, 바깥을 누르거나 뒤로 가기로 끝 |

| 아이콘 | 모든 앱을 아늑단 아이콘 형식으로: 손으로 그린 54종 + 아늑단 틀에 넣은 자동 아이콘 15,322종 / 앱마다 직접 고르기: 아늑단 아이콘, 내 사진(아늑단 틀 또는 둥근 사각형), 설치한 다른 아이콘 팩의 아이콘 / 전체를 다른 아이콘 팩으로 바꾸기 |
| 런처 아이콘 | 아늑이 런처 자체 아이콘을 청록·핑크·골드·네이비·지구본 아늑단 중에서 선택 |
| 제스처 | 위로 쓸기 / 아래로 쓸기 / 두 번 탭 / 두 손가락 오므리기·벌리기 → 앱 서랍, 검색, 알림창, 화면 끄기, 위젯 추가, 설정, 원하는 앱 / 아이콘마다: 홈·독 아이콘을 위로 쓸면 따로 고른 앱 열기 |
| 알림 배지 | 점 또는 숫자 (알림 접근 권한 필요), 폴더는 안의 앱 합계 |

| 모양 | 아이콘 크기 70–130%, 앱 이름 글자 크기(8–80px, 1픽셀 단위 · 기본은 휴대폰 글꼴 크기를 따라감), 라벨 켜기/끄기, 서랍·폴더 밝게/어둡게/시스템, 아늑단 배경화면 3종, 움직이는 배경(아늑단 패턴 흐르기·내 동영상·내 GIF — 기본은 런처 홈 화면, '휴대폰 배경화면으로 설정'을 고르면 홈·잠금 화면, 안 보이면 멈춤), 아이콘 색(전체 색·앱별 색, 직접 고르기, 배경화면 색 따르기) |

## 자동 검사

`main`에 올라갈 때마다 `.github/workflows/smoke.yml`이 Android 14 에뮬레이터에 설치해서 홈 화면, 앱 서랍·검색, 길게 누르기 메뉴, 끌어서 폴더 만들기(독·홈 화면, 다시 켠 뒤 유지), 서랍에서 홈으로 끌기, 서랍 형식·정렬·배경 바꾸기, 움직이는 배경(패턴·동영상·GIF), 아래로 쓸기(알림창), 배경화면 적용, 위젯 추가, 알림 배지 서비스, 아이콘 바꾸기(아늑단 아이콘·사진·아이콘 팩), 런처 아이콘 바꾸기, 설정 화면을 차례로 실행해요. 외부 아이콘 팩은 두 가지로 확인해요.

| 팩 | 확인하는 것 |
|---|---|
| `testiconpack` 모듈 (이 저장소, 시험용·배포 안 함) | 앱별 아이콘, 날짜 아이콘(`calendar_1`~`31`), `iconback`·`iconmask`·`iconupon`·`scale` 합성, 시계를 하루 넘겼을 때 달력 아이콘이 바뀌는지 |
| Arcticons (F-Droid에서 받는 실제 배포 팩, GPL-3.0) | 실제 팩 읽기(항목 수를 APK에서 직접 센 값과 비교), 전체 적용, 앱 하나에 팩 아이콘 고르기·검색, 어두운 서랍 |

화면 캡처와 로그는 `smoke-번호` 사전 릴리스에 올라가요.

## 외부 아이콘 팩

흔히 쓰는 안드로이드 아이콘 팩 형식(ADW 형식)을 읽어요. 아이콘 팩이 `org.adw.launcher.THEMES` 같은 동작으로 자신을 알리면 목록에 나오고, `appfilter.xml`(res/xml, res/raw, assets 중 하나)로 앱과 아이콘을 맞춰요. 팩에 없는 앱은 팩의 `iconback`·`iconmask`·`iconupon`·`scale` 규칙으로 꾸며요. `drawable.xml`이 있으면 앱별로 고를 때 그 목록을 보여 줘요. 날짜 아이콘(`<calendar prefix=...>`)은 오늘 날짜 그림을 쓰고, 자정·시계 변경·시간대 변경 때 다시 그려요. 큰 팩은 백그라운드에서 읽는 동안 "아이콘 팩 불러오는 중…"이 떠요.

흰 선으로 된 팩(예: Arcticons)은 밝은 앱 서랍에서 잘 안 보여요. 설정 → 테마 (앱 서랍·폴더) → 어둡게로 바꾸거나, 같은 팩의 밝은 배경용 버전을 쓰세요.

## 아늑단 아이콘

기본 아이콘 모드("아늑단 아이콘 (내장)")에서는 모든 앱이 아늑단 아이콘 형식으로 나와요.

| 순서 | 어떤 앱 | 아이콘 |
|---|---|---|
| 1 | 직접 고른 앱 | 고른 것 (아늑단 아이콘·사진·다른 팩) |
| 2 | 손으로 그린 54종에 맞는 앱 (브라우저, 카메라, 전화, 설정 등) | 손으로 그린 아늑단 아이콘 |
| 3 | 그 밖의 앱 중 Arcticons에 있는 앱 (약 4만 9천 개 앱 정보, 그림 15,322종) | 아늑단이 내다보는 타일 위에 앱 그림 (자동 생성) |
| 4 | 둘 다 없는 앱 | 같은 아늑단 틀 안에 원래 아이콘 |

3·4번은 설정 → "모든 앱을 아늑단 아이콘으로"를 끄면 원래 아이콘으로 돌아가요. 타일 색은 앱마다 청록·골드·핑크·흰색 중 하나로 정해져요. 앱 하나만 바꿀 때는 아이콘을 길게 눌러 아이콘 바꾸기 → "더 많은 아늑단"에서 이름으로 찾아요.

3번의 안쪽 그림은 [Arcticons](https://github.com/Arcticons-Team/Arcticons)(Donnnno와 기여자들)의 아이콘을 바꾼 것이고 **CC BY-SA 4.0**이에요. 바꾼 그림 데이터는 `app/src/main/assets/linecons/`에 있고 같은 라이선스로 공개해요(출처·바꾼 점: 그 폴더의 `NOTICE.txt`, 만드는 방법: `tools/linecons/README.md`). 앱의 설정 → 정보 → 아이콘 그림 라이선스에서도 볼 수 있어요. 아늑단 틀(`assets/catfmt`), 손으로 그린 54종, 나머지 코드는 이 라이선스 대상이 아니에요.

## 글꼴

설정 → 모양 → 글꼴에서 고를 수 있는 글꼴은 모두 [Google Fonts](https://github.com/google/fonts)에 있는 **SIL Open Font License 1.1** 무료 글꼴이에요. 파일과 라이선스 전문은 `app/src/main/assets/fonts/`에 있어요.

| 글꼴 | 만든 곳 | 넣은 방법 |
|---|---|---|
| 주아 (Jua) | Woowahan Brothers | 줄임본 |
| 개구 (Gaegu) | JIKJI SOFT | 줄임본 |
| 감자꽃 (Gamja Flower) | YoonDesign Inc | 줄임본 |
| 하이멜로디 (Hi Melody) | YoonDesign Inc | 줄임본 |

줄임본은 앱 크기를 줄이려고 자주 쓰는 한글 2,350자와 영문·숫자·기호만 남기고 힌팅을 뺀 거예요(`tools/fonts/subset.py`). 줄임본에 없는 글자는 휴대폰 기본 글꼴로 보여요.

## 서명 키

저장소 비밀값 `ANUKI_KEYSTORE_B64`(키 파일을 base64로 바꾼 내용)와 `ANUKI_KEYSTORE_PASS`(비밀번호)를 넣어 두면 항상 같은 키로 서명돼서 새 버전을 덮어 설치할 수 있어요. 없으면 빌드마다 임시 키로 서명해요.

## 알아둘 점

- **알림창 내리기** 제스처는 안드로이드 비공개 API를 써서 기기에 따라 안 될 수 있어요.
- **화면 끄기** 제스처는 '기기 관리자' 권한을 한 번 허용해야 해요. 이렇게 끄면 다음 잠금 해제 때 지문·얼굴 대신 PIN을 입력해야 할 수 있어요.
- 앱 바로가기 메뉴는 아늑이 런처가 **기본 홈 앱일 때만** 보여요 (안드로이드 정책).
- 배경화면 '스티커 모음'은 캐릭터 시트의 스티커를 잘라 만들었어요.
