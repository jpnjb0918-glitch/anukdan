# 아늑이 런처 (Anuki Launcher)

흰 고양이 캐릭터 아이콘으로 꾸민 안드로이드 홈 런처예요. 노바런처(Nova Launcher 8.9.4)의 기능 구성을 참고했고, **AI 기능·광고·분석 SDK·결제는 넣지 않았어요.**

## 설치

1. 이 저장소의 **Releases**에서 최신 `anuki-launcher.apk`를 휴대폰으로 받아요.
2. 설치할 때 "출처를 알 수 없는 앱" 허용을 물으면 허용해요.
3. 앱 목록의 **아늑이 런처 설정**을 열고 → **기본 홈 앱으로 설정**을 눌러요. (처음 홈 버튼을 눌렀을 때 아늑이 런처를 골라도 돼요.)

`main`에 올라갈 때마다 GitHub Actions가 APK를 새로 빌드해서 Releases에 올려요 (`.github/workflows/build.yml`).

## 기능

| 구역 | 기능 |
|---|---|
| 홈 화면 | 여러 페이지, 격자 열·행 조절(3–7 × 3–8), 독(3–7칸, 배경 켜기/끄기), 페이지 점 표시 |
| 편집 | 길게 눌러 끌어 옮기기, 아이콘 위에 놓으면 폴더 만들기, 화면 가장자리에 대면 페이지 넘김, 위쪽 바에 놓아 제거·앱 정보·설치 삭제 |
| 길게 누르기 메뉴 | 앱 바로가기(기본 홈 앱일 때), 앱 정보, 아이콘 바꾸기, 홈에서 제거, 설치 삭제 / 빈 곳: 위젯 추가·배경화면·빈 페이지 삭제·설정 |
| 앱 서랍 | 위로 쓸어 열기, 가나다 정렬, 검색(초성 검색 지원: `ㅋㅋㅇ` → 카카오톡), 사용자 탭, 앱 숨기기, 아래로 쓸어 닫기 |
| 폴더 | 이름 바꾸기, 색 4가지(청록·핑크·골드·네이비), 안의 앱 3개 미리보기 |
| 위젯 | 위젯 목록에서 추가(권한·설정 화면 처리), 옮기기, 크기 조절, 삭제 |
| 아이콘 | 기본 앱(브라우저·카메라·메시지·메일·갤러리 등)에 고양이 아이콘 자동 적용, 나머지 앱은 고양이 얼굴 테두리 안에 / 앱마다 직접 고르기: 고양이 아이콘 54종, 내 사진(고양이 틀 또는 둥근 사각형), 설치한 다른 아이콘 팩의 아이콘 / 전체를 다른 아이콘 팩으로 바꾸기 |
| 런처 아이콘 | 아늑이 런처 자체 아이콘을 청록·핑크·골드·네이비·지구본 고양이 중에서 선택 |
| 제스처 | 위로 쓸기 / 아래로 쓸기 / 두 번 탭 → 앱 서랍, 검색, 알림창, 화면 끄기, 위젯 추가, 설정, 원하는 앱 |
| 알림 배지 | 점 또는 숫자 (알림 접근 권한 필요), 폴더는 안의 앱 합계 |
| 백업 | 배치와 설정을 JSON 파일로 저장·복원, 홈 화면 초기화 |
| 모양 | 아이콘 크기 70–130%, 라벨 켜기/끄기, 서랍·폴더 밝게/어둡게/시스템, 고양이 배경화면 3종 |

## 노바런처 대비

노바런처 APK의 매니페스트(권한·화면 구성)를 기준으로 비교했어요. 코드나 그림은 가져오지 않았어요.

| 노바런처에 있는 것 | 아늑이 런처 |
|---|---|
| 홈 격자·독·페이지·폴더·위젯·앱 서랍·서랍 탭·앱 숨기기 | 있음 |
| 제스처(스와이프·두 번 탭), 알림 배지, 백업·복원 | 있음 |
| 아이콘 팩 적용, 앱별 아이콘 편집, 사진 아이콘 | 있음 (고양이 아이콘 팩 내장 + 외부 아이콘 팩) |
| AI 채팅·AI 인사이트 | **뺌** |
| 광고 SDK(Bytedance·Facebook·Moloco·Fyber 등), Firebase 분석, 결제(Stripe·Play Billing) | **뺌** |
| 연락처·캘린더 검색, 위치, 전화 관련 권한 | 없음 |
| 서랍 그룹 폴더, 페이지 전환 효과 선택, 아이콘 모양(적응형) 설정 | 아직 없음 |

## 구조

| 파일 | 역할 |
|---|---|
| `HomeActivity.kt` | 홈 화면 조립, 바인딩, 메뉴, 위젯 추가, 제스처 실행 |
| `DragController.kt` | 길게 누르기 → 끌기 → 놓기 처리 |
| `Layouts.kt` | 격자(CellLayout), 페이지 넘김(PagedView), 페이지 점, 드래그 레이어 |
| `UI.kt` | 앱 서랍, 폴더 창, 팝업 메뉴, 드롭 바 |
| `IconProvider.kt` | 아이콘 고르기 순서(앱별 선택 → 아이콘 팩), 고양이 테두리, 폴더 아이콘 |
| `IconPacks.kt` | 외부 아이콘 팩 찾기·appfilter 해석·대체 아이콘 합성 |
| `CustomIcons.kt` | 사진으로 아이콘 만들기 |
| `AppIcon.kt` | 런처 자체 아이콘 바꾸기 (activity-alias) |
| `LayoutModel.kt` | 홈 배치 저장(JSON) |
| `Prefs.kt` | 설정 저장 |
| `SettingsActivity.kt` | 설정 화면, 백업·복원 |
| `Services.kt` | 알림 배지 서비스, 화면 끄기 권한, 위젯 호스트 |

외부 라이브러리 없이 안드로이드 기본 API만 써요 (minSdk 26 = Android 8.0, targetSdk 34).

## 자동 검사

`main`에 올라갈 때마다 `.github/workflows/smoke.yml`이 Android 14 에뮬레이터에 설치해서 홈 화면, 앱 서랍·검색, 길게 누르기 메뉴, 끌어서 폴더 만들기, 서랍에서 홈으로 끌기, 아래로 쓸기(알림창), 배경화면 적용, 위젯 추가, 알림 배지 서비스, 아이콘 바꾸기(고양이 아이콘·사진·아이콘 팩), 런처 아이콘 바꾸기, 설정 화면을 차례로 실행해요. 외부 아이콘 팩은 두 가지로 확인해요.

| 팩 | 확인하는 것 |
|---|---|
| `testiconpack` 모듈 (이 저장소, 시험용·배포 안 함) | 앱별 아이콘, 날짜 아이콘(`calendar_1`~`31`), `iconback`·`iconmask`·`iconupon`·`scale` 합성, 시계를 하루 넘겼을 때 달력 아이콘이 바뀌는지 |
| Arcticons (F-Droid에서 받는 실제 배포 팩, GPL-3.0) | 실제 팩 읽기(항목 수를 APK에서 직접 센 값과 비교), 전체 적용, 앱 하나에 팩 아이콘 고르기·검색, 어두운 서랍 |

화면 캡처와 로그는 `smoke-번호` 사전 릴리스에 올라가요.

## 외부 아이콘 팩

ADW·노바 형식 아이콘 팩을 읽어요. 아이콘 팩이 `org.adw.launcher.THEMES`, `com.novalauncher.THEME` 같은 동작으로 자신을 알리면 목록에 나오고, `appfilter.xml`(res/xml, res/raw, assets 중 하나)로 앱과 아이콘을 맞춰요. 팩에 없는 앱은 팩의 `iconback`·`iconmask`·`iconupon`·`scale` 규칙으로 꾸며요. `drawable.xml`이 있으면 앱별로 고를 때 그 목록을 보여 줘요. 날짜 아이콘(`<calendar prefix=...>`)은 오늘 날짜 그림을 쓰고, 자정·시계 변경·시간대 변경 때 다시 그려요. 큰 팩은 백그라운드에서 읽는 동안 "아이콘 팩 불러오는 중…"이 떠요.

흰 선으로 된 팩(예: Arcticons)은 밝은 앱 서랍에서 잘 안 보여요. 설정 → 테마 (앱 서랍·폴더) → 어둡게로 바꾸거나, 같은 팩의 밝은 배경용 버전을 쓰세요.

## 서명 키

저장소 비밀값 `ANUKI_KEYSTORE_B64`(키 파일을 base64로 바꾼 내용)와 `ANUKI_KEYSTORE_PASS`(비밀번호)를 넣어 두면 항상 같은 키로 서명돼서 새 버전을 덮어 설치할 수 있어요. 없으면 빌드마다 임시 키로 서명해요.

## 알아둘 점

- **알림창 내리기** 제스처는 안드로이드 비공개 API를 써서 기기에 따라 안 될 수 있어요.
- **화면 끄기** 제스처는 '기기 관리자' 권한을 한 번 허용해야 해요. 이렇게 끄면 다음 잠금 해제 때 지문·얼굴 대신 PIN을 입력해야 할 수 있어요.
- 앱 바로가기 메뉴는 아늑이 런처가 **기본 홈 앱일 때만** 보여요 (안드로이드 정책).
- 배경화면 '스티커 모음'은 캐릭터 시트의 스티커를 잘라 만들었어요.
